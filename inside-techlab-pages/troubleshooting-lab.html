SOFTWARE ACADEMY / 005

Software Academy

Materi dasar software dan sistem komputer untuk siswa TKJ.

LEARNING MODULE

01 · Sistem Operasi

Sistem operasi mengelola perangkat keras, memori, file, proses, dan aplikasi. Contoh: Windows, GNU/Linux, dan Android.

  • Windows banyak digunakan pada PC umum.
  • Linux memiliki banyak distribusi, misalnya Ubuntu dan Debian.
  • Kernel menjadi inti pengelolaan sumber daya sistem.

02 · BIOS & UEFI

Firmware motherboard yang menginisialisasi perangkat dan memulai proses booting.

  • UEFI adalah penerus modern BIOS legacy.
  • UEFI mendukung fitur modern seperti Secure Boot.
  • Pengaturan firmware harus mengikuti panduan perangkat.

03 · Driver

Driver memungkinkan sistem operasi berkomunikasi dengan perangkat seperti GPU, audio, Wi-Fi, dan printer.

  • Unduh driver dari situs resmi produsen.
  • Cocokkan model perangkat dan versi OS.
  • Hindari paket driver tidak dikenal.

04 · File System

File system mengatur bagaimana data disimpan dan ditemukan pada media penyimpanan.

  • NTFS umum pada Windows.
  • FAT32 memiliki batas ukuran file 4 GB.
  • ext4 banyak digunakan di Linux.

05 · Jaringan Dasar

Jaringan menghubungkan perangkat agar dapat bertukar data.

  • IP address mengidentifikasi perangkat pada jaringan.
  • DNS menerjemahkan nama domain menjadi alamat IP.
  • Router meneruskan paket antarjaringan.

06 · Keamanan Software

Kebiasaan keamanan membantu melindungi perangkat dan data.

  • Perbarui OS dan aplikasi.
  • Gunakan kata sandi unik dan autentikasi berlapis.
  • Periksa sumber file sebelum memasang aplikasi.
